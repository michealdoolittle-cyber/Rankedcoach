# Gamesense Library assets

Local image copies used by the Gamesense Library.

- Map splash and tactical-layout art: `https://valorant-api.com/v1/maps`
- Agent portraits, icons, and ability icons: `https://valorant-api.com/v1/agents?isPlayableCharacter=true`
- Retrieved: 2026-07-12

The local copies avoid runtime hotlinking and keep the Library usable if the
community asset endpoint is temporarily unavailable. Refresh these files when
the corresponding gameplay reference data is reviewed after a patch.
