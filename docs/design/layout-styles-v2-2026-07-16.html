RankedCoach · Layout Style v2 — real HUD framing motifs, not border variants

Different shapes, not different corners.

The first 20 were mostly one idea repeated — a rectangle, restyled. This round pulls from actual sci-fi/HUD design vocabulary (corner brackets, circuit traces, portal rings, exploded-diagram leader lines) so each concept is a genuinely different framing device, not a border-radius variant. Same hard rule as before: every color below comes only from --accent / --accent-2 / --card — swap the buttons below to confirm nothing is hardcoded.
