RankedCoach · Layout Style Fonts — typography per style, fully optional

Every style gets a voice, not just a shape.

Each of the 20 Layout Styles gets a paired display font for headers and titles (body copy always stays on the app's normal readable font — never the display face). Two independent controls, so nobody's stuck with a look they don't want: a per-style Custom Font toggle that reverts to the app's default type when off, and a separate, standalone Font dropdown that works no matter what Layout Style — or none at all — is active.

Setting 1 — Custom Font toggle (per Layout Style)

Lives right under the Layout Style picker. Defaults to On when a style is first selected; flipping it off keeps every shape/border/tag rule from that style but swaps headers back to the app's normal font.
